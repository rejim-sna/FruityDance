# 🎵 FruityWidget

> *"Навайбкожено с любовью и нейросетями"* 🤖✨

Виджет для рабочего стола, который танцует под музыку! Персонаж меняет эмоции в зависимости от громкости звука.

## 🌊 Происхождение

Этот проект был **навайбкожен** — то есть написан в сотрудничестве с искусственным интеллектом, под настроение и с правильной энергетикой. В коде чувствуется дух экспериментов, чашечка кофе и немного магии нейросетей.

*"It's not a bug, it's a feature... created by AI"* 🧙‍♂️

## 📥 Установка

1. Скачай `fruitywidget_setup.py`
2. Запусти его (дважды кликни)
3. Всё установится автоматически!

## 🎮 Как пользоваться

- **Левая кнопка мыши** — перетащить виджет
- **Правая кнопка мыши** — закрыть
- **Колесико мыши** или клавиша **R** — перезагрузить настройки
- **ESC** — закрыть

## 🎨 Анимации

В папке `Документы/FruityWidget/Animations/` лежат гифки:
- `waiting.gif` — ожидание (тишина)
- `hula.gif` — спокойная музыка
- `stepping.gif` — средняя громкость
- `jumping.gif` — громкая музыка
- `windmill.gif` — очень громко
- `held.gif` — при перетаскивании

Можешь заменить их на свои! Дерзай, твори, вайби!

## ⚙️ Настройки

После первого запуска появится файл `Документы/FruityWidget/Config/settings.json`.

Что можно настроить:
- `window_width` / `window_height` — размер окна
- `frame_delay` — скорость анимации (мс)
- `threshold_*` — пороги громкости для каждой анимации
- `smoothing` — плавность реакции (0-1)

## ❓ Частые вопросы

**Виджет не слышит звук?**
Включи "Стерео-микшер" в настройках звука Windows.

**Хочу свои анимации!**
Просто замени гифки в папке `Animations/` и перезапусти виджет.

**Кто написал этот код?**
